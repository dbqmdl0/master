# 07. 라이선스·보안·권한 검토

> 전제: 회사의 M365 관리 권한과 보안 정책은 제한될 수 있다. 이 문서는 **정책을 우회하지 않고** 가능한 최대치를 설계한다. 가격은 2026-10-25 검색 확인 기준 미국 공시가(USD, 연간 약정)이며 한국 계약가·EA 할인과 다를 수 있다 — 견적은 IT/구매 경유.

---

## 1. 운영 시나리오 비교

| 구분 | Scenario A — 기본 권한형 | Scenario B — 팀 협업 확장형 | Scenario C — 고급 AI·전사 확장형 |
|---|---|---|---|
| 전제 권한 | 일반 사용자 M365 라이선스, 기존 목록 편집, 개인 흐름 | 팀 사이트 편집(목록·라이브러리 생성), Teams Workflows 앱 허용, 흐름 공동 소유 | Copilot 라이선스 또는 종량제 허용, Copilot Studio 환경, (필요 시) Premium·Graph 앱 등록 IT 승인 |
| 가능 기능 | P1: 기존 시제품 목록 열 추가 + 접수·SLA 흐름 / P2: Power Query 폴더 결합 + Python in Excel 검증 / P3: 메일 플래그 → 액션, 개인 아침 브리핑 / 제거 패키지 4종 | 파일럿 3개 전체(흐름 약 15개), Approvals, Office Scripts 자동 실행, 팀 다이제스트, 예외 리포트 | + AI 회의 추출(사람 선택), 결정 조회·지식 에이전트, Copilot 예약 프롬프트, Copilot in Excel/PPT 보고 초안, ERP/APS 연동(IT), Dataverse 이전 |
| 제한 사항 | 흐름이 개인 소유(이동·퇴사 위험), 팀 채널 게시 제약, 공장 데이터 자동 검증 없음(새로 고침 수동) | 표준 커넥터만, 마스터는 Excel(10만 행 이전 기준), 외부 공장 접근은 외부 공유 정책 의존 | 사용량 비용 변동(Copilot Credits), 데이터 거버넌스 심사, 에이전트 품질 관리 부담 |
| 예상 추가 비용 | **0** | **0** (내부 구축 시간만) | Copilot $30/사용자/월(기업·연간 약정) — 8명이면 $240/월 = **약 $2,880/년**; Copilot Studio 크레딧 팩 $200/월(25,000 크레딧, 테넌트) 또는 종량제; Power Automate Premium $15/사용자/월(필요 시 소유자만) |
| 기대 효과(가정) | 연 약 500~600h(제거 패키지 446h + 개인 자동화 일부) | 연 약 1,225h(파일럿 3개 순절감 합계) | B + 지식 검색·보고 초안 등 연 약 300~400h 추가(O07·O08·O32, 실측 전) |
| 구축 기간 | 1주 | 4주 | B 완료 후 4~8주 |

> Scenario C 비용 예시(가정 계산): Copilot 8명 × $30 × 12개월 = **$2,880/년**. 크레딧 팩 1개 × $200 × 12 = $2,400/년(사용량이 적으면 종량제가 유리할 수 있음). 금액 ROI는 `09` 모델의 H(시간당 인건비) 입력 후 계산.

## 3. 반드시 준수할 보안 규칙 → 이 설계에서의 이행 방식

| 규칙 | 이행 |
|---|---|
| 실제 기업 데이터·계정·토큰을 외부 AI에 전송 금지 | 모든 코드는 **가상 데이터**로만 테스트했다. AI 단계는 회사가 승인한 M365 테넌트 내 Copilot만 사용(Scenario C), 승인 전 비활성 |
| Claude Code에서 M365 연결 시 외부 AI·데이터 정책 우선 확인 | 이번 작업에서 Claude Code는 **테넌트에 연결하지 않았다**. 향후 연결(MCP·Graph)은 `12` D-06 승인 사항 |
| 공식·승인 API·커넥터 우선 | 표준 커넥터만 사용. PnP·Graph는 IT 승인 경로로만 |
| 관리자 권한 우회·정책 회피 제안 금지 | DLP 차단 시 '대체 설계(A-lite)'로 전환하고 정책 예외는 IT에 정식 요청 |
| 최소 권한 | 요청 부서 '본인 항목만 편집', 로그 읽기 전용, 마스터 편집은 운영자만, 에이전트는 읽기 전용 |
| 이메일 발송·삭제·대량 수정·권한 변경·운영 배포는 사전 승인 | 흐름의 외부 발송 없음(사내 Teams 메시지만). 대량 수정(기존 시제품 데이터 유형 지정)·권한 변경·테스트 데이터 삭제는 가이드에 '승인 후' 명시 |
| 검증 없이 운영 자동화·데이터 구조 변경 금지 | 백업(CSV) → 테스트 복제 목록 → 승인 → 원본 순서. 열 삭제 금지(숨김) |
| 비밀정보 하드코딩 금지 | 스크립트·흐름에 비밀번호·토큰 없음. PowerShell은 대화형 로그인·조직 등록 ClientId만 |
| DLP·감사·민감도 레이블·보존 확인 | Phase 1 진단 D3·D10. 보존 정책이 있으면 RequestLog·DecisionLog 삭제 금지 운영 |

## 5. 권한 때문에 막힐 때의 대체 설계

| 막힘 | 정책 위반 없는 대체 |
|---|---|
| 팀 사이트에 목록 생성 불가 | 기존 시제품 목록에 열 추가(편집 권한만) / 사이트 소유자에게 목록 생성 요청 |
| Workflows 앱 차단(Teams 카드 불가) | Outlook 메일 알림(받은편지함 규칙으로 폴더 분류) + Lists '알림 받기(Alert me)' 기능 |
| Power Automate DLP 차단 | Power Query(A-lite) + Lists 보기 + 수동 실행 Office Scripts(Excel 자동화 탭) |
| Office Scripts 비활성 | Power Query + 수식 검증(동적 배열) |
| Copilot 없음 | 모든 파일럿은 AI 없이 동작. 회의 추출은 '메시지 액션으로 사람이 기록' |
| 해외 공장 외부 공유 불가 | 메일 첨부 수신 → SCM이 제출 폴더에 저장 → 동일 자동 검증 |
