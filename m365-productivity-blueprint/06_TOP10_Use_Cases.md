## 3. 과제별 요약 (As-Is → To-Be)

1. **O03 결정·액션 레지스터** — 결정이 회의 참석자의 기억에 있다 → Teams 메시지에서 클릭 2번으로 DEC·ACT 생성, 기한 D-1/당일/초과 자동 리마인더, 3회 초과 시 결정권자 요약. *의존성: 없음. Pilot 03.*
2. **O01 아침 브리핑** — 여러 앱을 돌며 오늘 할 일 파악 → 07:40 카드 1장(점수 Top 5, 집중 가능 시간, 안건 없는 내 주관 회의 경고). AI 없이 규칙으로. *의존성: O03·O05 데이터가 있을수록 정확. Pilot 03.*
3. **O05 요청 허브** — 메일 요청·구두 진행 문의 → 1요청 1행, 영업일 SLA, 담당자별 다이제스트, 요청자는 링크로 상태 조회. 기존 시제품 목록 확장. *Pilot 01.*
4. **O04 데이터 계약** — 공장별 양식·복사·붙여넣기·늦은 오류 발견 → 계약 템플릿 제출 즉시 검증·반려/반영, 합격분만 단일 원본. *Pilot 02. O06·O08·O10·O11의 기반.*
5. **O02 메일→업무** — 받은 메일 플래그 = 액션, 보낸 메일 플래그 = 회신대기. 별도 앱 없음. *Pilot 03의 P3-F3에 포함.*
6. **O07 지식 에이전트** — Copilot 라이선스·정책 확인 시 결정 조회 에이전트(Pilot 03 자산)로 시작, 매뉴얼·회의록으로 확장.
7. **O21 커뮤니케이션 표준** — 증량·이월·지연·품질보류 4종 상황 템플릿(한/영) + Outlook 내장 번역. 데이터를 외부 번역 서비스에 넣지 않는다.
8. **O06 S&OP 변경 감지** — O04로 매주 쌓이는 PlanNextWeek·실적을 이용해 버전 간 변경이 임계값(예: ±15%, 동결구간 내 변경)을 넘으면 DecisionLog에 '결정요청'으로 자동 상정 → S&OP 회의 안건이 데이터에서 생성된다.
9. **O08 경영진 보고** — 마스터 → 고정 차트 범위 자동 갱신 → 핵심 메시지 초안은 규칙 문장(전주 대비·목표 대비) / C에서 Copilot. 최종 메시지는 사람이.
10. **O11 재고 건전성** — 예외 규칙 X04(재고 커버 >8주·<1주)를 매주 알림, 단산 SKU는 유효기한 대비 소진 예상 비교.
