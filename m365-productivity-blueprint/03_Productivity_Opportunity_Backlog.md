# 03. 업무 생산성 혁신 백로그 (35개)

> 도출 방법: `01` 문서의 업무 원자 분해(Trigger→Control) → 전제 제거 질문 8개 → **Eliminate → Simplify → Standardize → Integrate → Automate → Augment** 순서로 적용.
> ★ = 기존에는 불가능하거나 비현실적이었지만 데이터·자동화·AI 결합으로 가능해지는 **새 업무 방식**.
> 정량값(연간 순절감시간)은 모두 **가정**이다. 산식·가정값은 `04_Prioritization_Matrix.csv`, 생성 코드는 `tools/build_backlog.py`.

## 8. 사용자가 아직 인지하지 못했을 가능성이 높은 기회 (요약)

1. **결정 대기시간을 KPI로 만든다(O15)** — 조직 속도의 진짜 병목은 작업 시간이 아니라 '결정 대기'인 경우가 많은데, 지금은 측정조차 되지 않는다.
2. **데이터 계약(O04)** — 문제는 Excel이 아니라 '합의되지 않은 양식'이다. 공장과 14개 열·10개 규칙만 합의하면 취합 업무 자체가 사라진다.
3. **보고서 대신 '보이는 상태'(O17·O14)** — 보고를 자동화하지 말고 없앤다. 자동 생성된 다이제스트는 보고서가 아니라 데이터 조회 결과다.
4. **대화를 데이터로(P1-F4·P3-F1)** — Teams 메시지 '추가 작업'에서 바로 요청·결정·액션을 만든다. 입력 양식을 따로 열 필요가 없다.
5. **보낸 메일 플래그 = 회신 대기 추적(O02)** — 표준 Outlook 기능 조합만으로 '내가 기다리는 것' 목록이 생긴다.
6. **AI 출력의 기계적 검증(extraction_guard)** — AI가 쓴 근거 문장이 원문에 실제로 있는지 코드로 검사한다. AI를 '믿는' 대신 '검증'한다.
