## 3. 자체 검토에서 발견해 고친 것
1. **승인 대기와 동시성 충돌**: P1-F2에 동시성 1을 두면 승인 대기 중인 실행이 다른 모든 요청 처리를 막는다 → 동시성 해제 + Prev열 패턴 + 응답 시 현재 상태 재확인으로 변경.
2. **SKU 마스터 누락 시 검증 통과 위험**: 빈 마스터면 SKU 검사가 생략되던 로직 → 파일 단위 반려(fail-closed)로 수정, 테스트 추가.
3. **에스컬레이션 기준일 계산 불일치 위험**: Flow용 '단일 기준일' 방식과 영업일 규칙의 동치성을 3,150개 조합으로 전수 검증하는 테스트 추가.
4. **TOP10 왜곡**: 규칙 변경형 과제(링크 공유 등)가 점수 1위가 되어 구축 과제를 밀어냄 → '제거 패키지'로 분리하고 흡수 관계를 코드로 명시해 재현 가능하게.
5. **과대 추정**: O26(링크 공유) 478h → 113h, O34 107h → 30h로 건수 가정 하향.
6. **카드 표준 외 속성**: Adaptive Card에서 `$comment` 제거.
7. **Mermaid 문법 위험**: 점선 라벨·비ASCII 참가자 ID 수정 후 브라우저 파서로 전수 검증.
8. **회의 수 집계 오류**: 종일 일정이 회의 수에 포함되던 문제 수정(테스트로 확인).
