# Copilot 회의 결정·액션 추출 프롬프트 (붙여넣기용)

> 사용처 ① Teams 회의 종료 후 **회의 채팅 › 요약(Recap) 탭 › Copilot** 에 질문 / ② **Microsoft 365 Copilot 앱(Copilot Chat, 업무 탭)** 에 회의록을 붙여넣고 질문
> 결과(응답 전체)를 그대로 복사해 `MeetingIntake` 목록의 **Copilot 추출 결과**에 붙여넣는다. 코드 블록 표시(```)나 앞뒤 설명이 섞여도 검증 스크립트가 JSON만 추출한다.
> 회의록 원문도 **회의록 원문** 칸에 같이 붙여넣어야 한다 — 근거 문장이 원문에 실제로 있는지(G2) 기계적으로 검사하기 때문이다.
> 회사가 승인한 Microsoft 365 Copilot(업무 계정)만 사용한다. 개인 계정·외부 AI 서비스에 회의 내용을 넣지 않는다.

## 프롬프트 (그대로 복사)

```text
이 회의에서 나온 '결정사항'과 '후속조치(액션)'만 아래 JSON 형식으로 추출해 줘. 규칙:
1) 회의에서 명시적으로 나온 내용만. 추측하거나 보완하지 마.
2) evidence에는 근거가 된 발언을 회의록에서 글자 그대로 복사해(8자 이상). 요약하거나 고쳐 쓰지 마.
3) owner_name/decided_by에는 회의에 나온 사람 이름만. 이메일 주소를 만들지 마. 불분명하면 null.
4) 기한이 명시되지 않았으면 due_date와 due_text를 모두 null. 기한 표현이 있으면 due_text에 원문 그대로, due_date는 회의일 기준 YYYY-MM-DD.
5) "검토해 보자"처럼 확정되지 않은 논의는 결정이 아니다.
6) 같은 액션을 두 번 쓰지 마. 결정과 연결된 액션은 decision_ref에 결정 순번(1부터).
7) JSON 한 개만 출력해.
{"decisions":[{"text":"","decided_by":null,"evidence":""}],"actions":[{"title":"","owner_name":null,"due_date":null,"due_text":null,"decision_ref":null,"evidence":""}]}
회의일: (예: 2026-10-26)
```

## 전사(Transcript)가 없는 회의
회의 메모를 회의록 원문 칸에 붙여넣고, Copilot Chat에 "아래 메모에서 …"로 같은 프롬프트를 사용한다. 근거 검사는 메모 기준으로 동작한다.

## 품질 합격선(4주 파일럿)
| 지표 | 계산 | 합격선 |
|---|---|---|
| '추천' 후보 채택률 | 승인 ÷ (승인+기각) — `tools/kpi_report.py` 4장 | ≥ 90% |
| 지어낸 기한 | G4 '기한 근거 표현 없음' 건수 | 0건 유지 |
| 회의당 확인 시간 | 후보 확인~승인 완료(시간기록) | ≤ 3분 |
미달 시 AI 단계를 끄고 Teams 메시지 액션(P3P-F5)으로 사람이 직접 기록한다(나머지 흐름은 그대로 동작).
