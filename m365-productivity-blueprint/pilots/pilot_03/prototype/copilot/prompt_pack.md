# 바로 쓰는 Copilot 프롬프트 팩 (SCM 반복 문서용)

> 사용처: Outlook·Excel·Word의 Copilot, 또는 Microsoft 365 Copilot 앱 '업무' 탭. 회사 계정 Copilot만 사용.
> 원칙: Copilot 결과는 **초안**이다. 수치·날짜·공장코드는 원문과 대조한 뒤 보낸다. 실제 데이터 입력 전 회사 Copilot 정책 확인(`APPROVALS.md` I-04).
> 효과 측정: 쓸 때마다 시간기록 비고에 '프롬프트 #번호, 절약 추정 분'을 적는다.

## #1 공장 자료 첫 확인 (Excel의 Copilot, 공장 파일을 연 상태)
```text
이 통합 문서에서 지난주 대비 생산량·출하량·재고가 20% 이상 바뀐 품목을 표로 보여 줘. 열: 품목, 지난주, 이번 주, 변화율, 비고. 합계가 맞지 않는 행이 있으면 따로 표시해 줘. 숫자는 파일에 있는 값만 쓰고 추정하지 마.
```

## #2 회신 대기 후속 메일 초안 (Outlook, 보낸 메일을 연 상태)
```text
이 메일에 아직 답이 없어서 정중하게 다시 확인을 요청하는 짧은 메일을 써 줘. 처음 요청한 내용과 기한을 한 줄로 다시 적고, 회신이 어려우면 가능한 날짜를 알려 달라는 문장을 넣어 줘. 5문장 이내.
```

## #3 해외 법인 공급 조정 안내 (Outlook, 한·영)
```text
아래 결정 내용을 해외 법인 담당자에게 알리는 영어 메일로 써 줘. 첫 문단에 결론(수량·시점), 둘째 문단에 이유, 마지막에 확인 요청. 숫자와 날짜는 내가 준 그대로 쓰고 새 정보를 만들지 마.
결정 내용: (예: 11월 증량 6,000 확정, 잔여 6,000은 12월 첫 주 선적)
```

## #4 S&OP 회의 전 이슈 정리 (Copilot 앱 '업무' 탭)
```text
지난 2주 동안 내가 받은 메일과 Teams 채팅 중 생산 차질, 원부자재 수급, 선적 지연, 품질 보류와 관련된 내용을 이슈별로 묶어 표로 정리해 줘. 열: 이슈, 관련 공장·품목, 최근 상황, 필요한 결정, 출처(메일·채팅 링크). 결정이 이미 난 건 제외해 줘.
```

## #5 주간 정리 메일을 보고서 문체로 (Outlook, F12 주간 정리 메일을 연 상태)
```text
이 메일 내용을 팀장 보고용 주간보고로 바꿔 줘. 형식: ① 핵심 3줄 ② 완료 ③ 이슈·도움 필요 ④ 다음 주 계획. 항목과 숫자는 메일에 있는 것만 쓰고, 없는 내용을 추가하지 마.
```
