# Copilot 예약 프롬프트 — 받은편지함·채팅 요약 (아침 브리핑 보완)

> 아침 브리핑(P3P-F6)은 **목록에 구조화된 미결 항목**만 다룬다. 아직 구조화되지 않은 메일·채팅은 Copilot 예약 프롬프트로 요약해 역할을 나눈다.
> 요건: Microsoft 365 Copilot 라이선스(보유 확인됨) + 표준 Power Automate. 관리자가 연결된 경험을 꺼두었으면 메뉴가 보이지 않는다(IT 확인 항목).
> 최대 10개 예약 가능. 2026-08부터 '연결된 경험' 범주로 이동(공식 문서 S36).

## 설정 순서
1. Microsoft 365 Copilot 앱(또는 Teams의 Copilot) → **업무(Work)** 탭에서 아래 프롬프트를 한 번 실행
2. 보낸 프롬프트에 마우스를 올림 → **이 프롬프트 예약(Schedule this prompt)**
3. 빈도: 매주 월~금, 시간 07:30(아침 브리핑 07:40 직전) → **저장(Save)** *(버튼 이름은 '저장' 또는 '저장 및 활성화'로 문서마다 다름)*
4. 관리: Copilot 앱 오른쪽 위 메뉴 → 예약된 프롬프트

## 프롬프트
```text
지난 업무일 오후 5시 이후 내가 받은 메일과 Teams 채팅 중에서 (1) 나에게 결정이나 회신을 요청한 것, (2) 기한이 언급된 것, (3) 공장·해외법인·품질 이슈를 각각 최대 5개만 표로 정리해 줘. 각 항목에 보낸 사람, 한 줄 요약, 원문 링크를 붙여 줘. 이미 내가 회신한 건은 빼 줘. 추측하지 말고 원문에 있는 내용만 써.
```

## 판단 기준
- 요약에서 '할 일'로 보이면 해당 메일에 **플래그**만 한다 → P3P-F1이 액션으로 등록 → 내일 브리핑에 점수 반영.
- 요약은 참고용이다. 목록(ActionItems·DecisionLog)이 유일한 원본이다.
