## 1단계. 목록 2개 만들기 (1주차, 40분)

먼저 **ActionItems(할 일 목록)** 와 **FlowErrorLog(자동화 오류 기록)** 2개만 만든다.

### 1-1. CSV로 목록 만들기 (목록마다 반복)
1. `microsoft365.com` → 왼쪽 **앱** → **Lists**
2. **+ 새 목록** → **CSV에서**
3. `lists/ActionItems.csv` 선택 → 각 열의 형식을 아래처럼 고르기
   - `DueDate`, `CompletedAt`, `LastRemindedAt` → **날짜**
   - `ReminderCount` → **숫자**
   - `Status`, `Priority`, `ActionType`, `Source`, `CreatedVia` → **선택(Choice)**
   - 나머지 → **한 줄 텍스트**(`Evidence`는 여러 줄 텍스트)
4. 저장 위치 **내 목록**, 이름은 반드시 영문 그대로 `ActionItems` → **만들기**
5. 같은 방법으로 `lists/FlowErrorLog.csv` → 이름 `FlowErrorLog`
   - `Severity` → **선택**(`Critical`, `Warning`) · `Resolved` → **예/아니요** · `ErrorMessage` → 여러 줄 텍스트 · 나머지 한 줄 텍스트

### 1-2. 열 다듬기 (ActionItems, 15분)
열 이름을 클릭 → **열 설정 → 편집**:
- **선택 열의 선택지를 정확히** 맞춘다(띄어쓰기까지). `LISTS_SETUP.md`의 ActionItems 표에서 복사
  - Status: `미착수, 진행중, 완료, 보류, 취소` (기본값 미착수)
  - ActionType: `실행, 회신대기` (기본값 실행)
  - Source: `회의, 이메일, Teams 메시지, 업무요청, 기타`
  - CreatedVia: `수동, Teams 메시지, Outlook 플래그, AI 제안 승인`
  - Priority: `높음, 보통, 낮음`
- **Owner(담당자)** 열: CSV에서는 글자로 들어온다 → 이 열 **삭제** → **+ 열 추가 → 사람** → 이름을 **영문 `Owner`로 먼저** 만들고 저장 → 다시 편집해서 표시 이름만 `담당자`로 바꾸기
  > 처음부터 한글 이름으로 만들면 자동화가 그 열을 못 찾는다. **항상 영문으로 만들고 나중에 한글로 바꾼다.**
- 다른 열도 표시 이름을 한글로 바꿔도 된다(예: `Title` → 할 일). 내부 이름은 그대로 남는다.

✅ 확인: ActionItems에 `[가상]`으로 시작하는 4줄이 보이면 성공. 담당자 칸이 비었으면 본인 이름을 골라 넣는다.

### 1-3. 주소 적어두기
ActionItems 목록을 연 상태에서 주소창 주소를 복사해 메모장에 붙여둔다.
예: `https://회사-my.sharepoint.com/personal/내계정/Lists/ActionItems/AllItems.aspx`
→ 이 중 **`/Lists` 앞부분까지**가 앞으로 쓸 **사이트 주소**다.

## 2단계. 첫 자동화: "메일에 플래그 → 할 일 등록" (1주차, 40분)

### 2-1. 흐름 만들기
1. `make.powerautomate.com` → 왼쪽 **+ 만들기** → **자동화된 클라우드 흐름**
2. 흐름 이름: `P3P-F1 메일 플래그(Inbox) → 실행 등록`
3. 트리거 검색창에 `flagged` → **When an email is flagged (V4)** (Office 365 Outlook) 선택 → **만들기**
4. 트리거 카드 클릭 → 폴더: **Inbox(받은 편지함)**
5. 트리거 카드 **설정(Settings)** → **동시성 제어** 켜기 → **병렬 처리 수준 1** → 완료
   (같은 메일이 동시에 두 번 처리돼 중복되는 것을 막는다)

### 2-2. 액션 넣기 — `BUILD_TABLES.md`의 'P3P-F1' 표를 옆에 열어두고 위에서부터 한 줄씩
| 순서 | 하는 일 | 요령 |
|---|---|---|
| 1 | **+ → 작성(Compose)** 추가 → 이름을 `Config`로 바꾸기 | 이름 바꾸기 = 카드의 **… → 이름 바꾸기**. 입력칸에 표의 `{"site": ...}` 내용을 붙여넣고 `{{SITE_URL}}`은 1-3의 사이트 주소로, `{{ME}}`는 내 이메일로 바꾸기. 나머지 `{{...}}`는 지금은 그대로 둬도 된다 |
| 2 | **+ → 범위(Scope)** 추가 → 이름 `Try` | 이후 액션은 **전부 이 Try 상자 안쪽의 +** 로 추가 |
| 3 | 표의 2.1 ~ 2.5 순서대로 추가 | **액션 이름을 표와 똑같이**(대소문자·밑줄 포함) 바꾸는 것이 가장 중요하다. 식이 이름으로 서로를 찾기 때문이다 |
| 4 | Try 아래(바깥)에 **범위** 추가 → 이름 `Catch` → **… → 실행 후 구성** → '실패함'·'시간 초과됨'만 체크 | 오류가 나면 FlowErrorLog에 기록된다 |
| 5 | Catch 안에 표의 3.1 ~ 3.3 | |

**식 넣는 법(가장 많이 하는 일):**
- 표에 **fx** 라고 적힌 값 → 입력칸 클릭 → **fx(식)** 아이콘 → 식 붙여넣기 → **추가**
- 표에 `@{...}`로 적힌 값 → 입력칸에 그대로 붙여넣기 → 보라색 조각으로 바뀌면 성공. 안 바뀌면 fx 창에 중괄호 `{ }` 안의 내용만 넣기
- **조건(Condition)** → 왼쪽 칸에 fx 식, 가운데 `is equal to(같음)`, 오른쪽 칸에 fx로 `true`
- SharePoint 액션의 사이트·목록 칸 → 드롭다운 대신 **사용자 지정 값 입력** → 표의 값

### 2-3. 저장하고 시험
1. **저장** (이때 경고가 뜨면 0-2의 5번 → 경고를 캡처해 IT에 문의)
2. 본인에게 테스트 메일을 보낸다: 제목 `[테스트] 11월 증량 확인`
3. 받은 편지함에서 그 메일에 **플래그**
4. 1~3분 뒤 ActionItems 목록 새로 고침 → `[메일] [테스트] 11월 증량 확인`이 생겼으면 **성공**
5. 같은 메일 플래그를 껐다 다시 켜기 → **목록에 한 줄만 있어야** 정상(중복 방지)

**안 되면:** Power Automate → **내 흐름** → 흐름 클릭 → 아래 **실행 기록**에서 빨간 실행 클릭 → 빨간 액션을 열어 오류 문구 확인 → 아래 '막혔을 때' 표.

4. 처음 한 번은 실행 기록에서 트리거 출력을 열어, `BUILD_GUIDE.md` 4.3 표의 칸 이름(`cardOutputs`, `messagePayload` 등)이 실제와 같은지 확인한다. 다르면 `Inputs`·`Content` 두 액션만 고친다.

## 7단계. Copilot 회의 정리 (3주차, 1.5시간)

### 7-1. 목록·흐름 준비 (1시간)
- 목록 `TeamRoster`(팀 명부: 이름·이메일·별칭), `MeetingIntake`(회의 접수), `ActionCandidates`(AI 후보)를 만든다
- 흐름 `P3P-F8`(검증), `P3P-F9`(승인분 등록)를 표대로 만든다. F9 트리거는 **동시성 1** 필수

### 7-2. 실제 사용 순서 (회의 1건당 약 3분)
1. 회의가 끝나면 Teams 회의 채팅 **요약(Recap)** 탭의 Copilot에, 또는 Copilot 앱에 회의록과 함께 `copilot/meeting_extraction_prompt.md`의 프롬프트를 붙여넣는다
2. **MeetingIntake** 목록 → **+ 새로 만들기**
   - 회의명·회의일
   - 회의록 원문(전사 또는 메모)
   - Copilot 추출 결과(**응답 전체 복사**, ``` 표시가 섞여도 괜찮다)
   - **저장**
3. 1~2분 뒤 Teams에 "후보 N건" 메시지가 온다
4. **ActionCandidates** 목록에서 각 후보의 **근거 문장**을 읽고 '처리' 칸을 `승인` 또는 `기각`으로 바꾼다
   - '검토필요'로 표시된 것은 사유를 읽고 담당자 이메일·기한을 고친 뒤 승인
5. 승인한 것만 할 일·결정 목록에 등록된다. **AI가 혼자 등록하는 일은 없다.**

> ⚠ **실제 회의 내용을 넣기 전에** 회사의 Copilot 사내 데이터 사용 정책을 확인한다(`APPROVALS.md` I-04). 확인 전에는 `automation_assets/sample_data/mock_transcript.txt`(가상 회의록)로 연습한다.

### 7-3. (선택) 결정 조회 도우미·아침 메일 요약
- `copilot/decision_agent_setup.md`: "그거 누가 언제 결정했지?"를 묻는 Copilot 에이전트(10분)
- `copilot/scheduled_prompt.md`: 매일 07:30 받은 메일·채팅 요약(5분)

## 8단계. 효과 측정·보고 (4주차, 1시간)
1. 3~4주차 중 5일 동안 0-3과 같은 시간 기록(구분 `적용후`)
2. ActionItems·DecisionLog·ActionCandidates 목록에서 각각 **내보내기 → CSV로 내보내기** → PC의 한 폴더에 저장(**저장소에 올리지 않는다**)
3. PC에 Python이 있으면: `python3 tools/kpi_report.py report <폴더> --timelog <시간기록.csv>`
   없으면: 엑셀로 업무별 일평균 '기준선 vs 적용후'만 비교해도 된다
4. 팀장 보고 3줄:
   - 하루 ○분 줄었다(실측)
   - 기한 초과 할 일이 ○% 줄었다
   - 팀으로 넓히려면 ① 팀원 명부 ② 팀원에게 알림 발송 ③ 주간보고·현황회의 축소 실험, 이 세 가지 승인이 필요하다
5. 목표: 개인 기준 연 약 109시간(가정)의 70% 이상이 실측되면 팀 확산을 제안한다

## 막혔을 때

| 증상 | 원인 | 해결 |
|---|---|---|
| 흐름이 계속 반복 실행됨 | 3단계·6단계 **트리거 조건** 누락 | 흐름 끄기 → 트리거 조건 추가 → 다시 켜기 |
| "The expression is invalid" | 따옴표가 ‘ ’(둥근 따옴표)로 바뀜, 괄호 누락 | 메모장에 붙였다가 다시 복사, 표에서 원문 다시 복사 |
| 식에서 "액션을 찾을 수 없음" | 액션 이름이 표와 다름 | **… → 이름 바꾸기**로 표와 똑같이(밑줄 포함) |
| 목록에 아무것도 안 생김 | 사이트 주소·목록 이름 오타, 열 내부 이름이 한글로 생성됨 | 1-3 주소 다시 확인, 열은 영문으로 다시 만들기 |
| 선택 값 오류("선택지에 없는 값") | 선택지 철자·띄어쓰기 불일치 | 1-2 선택지를 표에서 복사해 맞추기 |
| 401·연결 오류 | 로그인 연결 만료 | Power Automate 왼쪽 **연결** → 빨간 연결 → **연결 수정** |
| 403 권한 오류 | 목록·파일 권한 없음 | 내 목록인지, 파일이 내 OneDrive에 있는지 확인 |
| Teams 카드가 안 옴 | Workflows 앱 차단 | 메일로 대신 오는지 확인 → IT 요청 |
| Teams 메시지 메뉴에 흐름이 안 보임 | 기본 환경이 아님 | Power Automate 오른쪽 위 환경을 '기본(default)'으로 바꿔 다시 만들기 |

**도움이 필요하면** 실행 기록의 **오류 문구와 실패한 액션 이름**만 복사해서 물어보면 된다. 회사 메일 내용·회의록은 붙여넣지 않는다.
