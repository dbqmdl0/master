# 01. 실행 파일럿 선정 — Pilot 03 결정–액션 루프 + 아침 브리핑

> 기준일 2026-10-25 · 사용자 답변 반영: ① 팀 SharePoint 사이트에 목록 생성 **가능** ② Microsoft 365 Copilot 유료 라이선스 **보유(사내 계정)** ③ 공장 Excel 수신은 **불규칙(대중 없음)**

## 1. 답변이 바꾼 판단

| 답변 | 설계 영향 |
|---|---|
| 목록 생성 가능 | Scenario B(팀 사이트 Lists)가 가능 → 세 파일럿 모두 데이터 구조 구현 가능 |
| Copilot 보유 | 기존 설계에서 '선택'이던 AI 단계를 실제로 쓸 수 있다: 회의 결정·액션 추출, 결정 조회 에이전트, 예약 프롬프트. 단 **Power Automate에서 Copilot을 직접 호출하는 표준 액션은 확인되지 않아** 반자동(사람이 Copilot 실행 → 붙여넣기 → 자동 검증)으로 설계 |
| 공장 Excel 불규칙 | Pilot 02의 전제(주 1회 정기 제출 → 계약 템플릿)가 성립하지 않는다. 수신 패턴부터 측정해야 하므로 **지금 착수하면 효과·기준선 모두 불확실** |

## 2. TOP 3 재평가 (현재 권한·라이선스 기준)

| 기준 | P1 업무요청 허브 | P2 공장 데이터 계약 | **P3 결정–액션 루프** |
|---|---|---|---|
| 사용자 권한만으로 구현 | 부분 — 요청 부서가 써야 효과 | 부분 — 공장 참여·외부 공유 확인 필요(Q-07) | **예 — 본인 메일·일정·목록으로 시작** |
| 필요한 라이선스 | 표준 | 표준 | 표준 + **Copilot(보유)** |
| 연간 순절감(블루프린트 가정, 팀 8명) | 285h | 263h → 불규칙 수신으로 신뢰도 낮음 | **676h**(조직 결정 없이도 378h) |
| 개인 파일럿 4주 안 체감 효과 | 낮음(타부서 이용 전) | 낮음 | **높음(첫날부터 브리핑·메일 캡처)** |
| 효과 측정 용이성 | 중 | 낮음(수신 패턴 불규칙) | **높음(시간기록 + 목록 데이터 자동 집계)** |
| 운영 리스크 | 타부서 노출 | 공장 데이터 품질 책임 | **낮음(본인 범위, 알림은 본인에게만)** |

**선정: Pilot 03.** 현재 권한·라이선스만으로 구현 가능하고, 다른 부서·공장의 참여 없이 첫날부터 효과가 나며, 업무시간 절감 기대치가 가장 크다.

## 4. Pilot 02에 대한 권고 (중단이 아니라 순서 변경)
'불규칙'은 아직 측정되지 않았다는 뜻이다. Pilot 03의 메일 플래그 흐름을 그대로 쓰면 측정할 수 있다: **4주 동안 공장에서 온 Excel 메일에 플래그만 한다** → ActionItems의 '[메일]' 항목(제목·근거 문장에 공장명·자료명이 남음)을 내보내 발신 공장·요일·자료 종류별 건수를 집계하고, 정기화할 수 있는 자료만 데이터 계약으로 전환한다.
