## 2. 설계상 의도적으로 하지 않은 것
- **AI 결과 자동 등록** — 사람 승인 없이 등록하지 않는다(Human-in-the-loop). 가드는 '추천/검토필요' 판정만 한다.
- **다른 사람에게 자동 발송** — `prototypeMode`로 차단. 본인 메일 대체 발송도 본인 주소만(에뮬레이터도 본인 외 발송을 거부).
- **데이터 삭제** — 재검증 시 이전 후보는 '기각' 처리(삭제 아님).
- 'Post adaptive card and wait for a response' — 폐지 여부 출처 상충 → 승인은 목록 상태 변경으로.

## 3. 에뮬레이터의 한계 (로컬 테스트를 과신하지 않기 위해)

| 항목 | 에뮬레이터 | 실제 Power Automate와의 차이 가능성 |
|---|---|---|
| 식 함수 | 사용하는 50여 개만 구현, 미구현 함수는 오류 | 날짜 형식 지정자는 yyyy·MM·dd·HH·mm·ss·fff만 |
| 범위(Scope) 상태 | 안쪽 실패가 있으면 '실패' | 실제 엔진의 세부 규칙과 다를 수 있으나, 설계는 Catch 마지막에 Terminate(실패)로 명시해 의존하지 않음 |
| 동시성 | '병렬 배치는 같은 시점 데이터를 읽는다'로 경합을 단순화 | 실제 경합 창은 더 짧거나 길 수 있음 → 동시성 1 + 재확인 이중 방어 |
