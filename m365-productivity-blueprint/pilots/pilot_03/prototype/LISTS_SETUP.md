|---|---|---|---|---|---|---|

| `Owner` | 담당자 | 사람(Person) | 예 |  | 예 |  |
| `DueDate` | 기한 | 날짜 및 시간 (날짜만) |  |  | 예 |  |
| `Status` | 상태 | 선택(Choice) | 예 | 미착수, 진행중, 완료, 보류, 취소 / 기본값 `미착수` | 예 |  |
